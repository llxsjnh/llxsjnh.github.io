Hexo文章资源文件夹图片引用问题

发表于2026-01-18|更新于2026-01-19|Hexo
|浏览量:

根据 Hexo 官方文档的说法，网站初始化完成后，source 文件夹中，除了文章以外，还存放诸如图片、CSS、JS文件等资源。例如，创建图片文件夹 /source/img，并在其中放一张图片 test.jpg。那么在文章中，可以使用 ![](/img/test.jpg)来引用该图片。

然而，随着文章数目越来越多，其中要引用的图片可能会越来越多。这种情况下，所有文章要引用的图片都放在 /source/img 下（当然这也可以），繁杂难找，也不好管理。

为此 Hexo 提供了更优雅的方式，为每篇文章创建资源文件夹。具体地：在配置文件 config.yml 中，将 post_asset_folder的值设置为 true。之后，通过 hexo new新文章时，会同时创建一个与文章文件名称相同的文件夹用于存放相关资源。在文章中，可以通过相对路径来引用。

上述操作搞完之后，我整了一篇文章，其中引用了图片。在本地预览时图片可以正常显示，但是启动服务后在浏览器预览却不行：图片没加载上。

这也怪我，看文档走马观花，没看全。在官方文档中有说明：通过常规 markdown 语法和相对路径引用图片或其它资源可能会导致显示不正确。对于图片，要使用 asset_img标签插件：

例如，我这篇文章的文件名是“Trouble for displaying image”，在同名资源文件夹下存放了一张图片 tsy.jpg。如果使用常规 markdown 语法，应该是 ![](./Trouble%20for%20displaying%20image/tsy.jpg)（其中%20表示空格），但网页浏览时无法正常显示出图片。根据上述标签插件，依次使用过如下几种形式：

  1. {% asset_img "./Trouble for displaying image/tsy.jpg" %}
  2. {% asset_img "./Trouble%20for%20displaying%20image/tsy.jpg" %}
  3. {% asset_img "tsy.jpg" %}
  4. {% asset_img tsy.jpg %}

上述引用形式中，1、2无效，而3、4是有效的。这说明使用 asset_img标签插件能自动识别文章资源文件夹，只需要指出资源文件名称即可。

启用该选项后，就可以使用常规 markdown 语法引用图片，Hexo会自动解析出图片的正确路径。但还是要注意，引用图片时，只需要指出资源文件名称即可。也就是说，如果引用前文图片，则语法是 ![](tsy.jpg)，而不能使用 ![](./Trouble%20for%20displaying%20image/tsy.jpg)。虽然图片无法本地预览，但是在浏览器中可以显示，这正是目的所在。
